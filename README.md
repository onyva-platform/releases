# ONYVA

ONYVA is a place to practice spoken French in small live conversations with people at your level.

This repository publishes the desktop app. The files here are installers. The application source code is not in this repository.

## Download the latest version

| Platform | File |
| --- | --- |
| Windows | [ONYVA-windows-setup.exe](https://github.com/onyva-platform/releases/releases/download/latest/ONYVA-windows-setup.exe) |
| macOS | [ONYVA-macos.dmg](https://github.com/onyva-platform/releases/releases/download/latest/ONYVA-macos.dmg) |
| Linux | [ONYVA-linux.AppImage](https://github.com/onyva-platform/releases/releases/download/latest/ONYVA-linux.AppImage) |

You can also start in the browser at [getonyva.com](https://getonyva.com).

## Releases

Every build has a version like `202610.22.1`. The date is UTC (`YYYYMM.DD`), and the last number starts at `1` each day.

The release named [latest](https://github.com/onyva-platform/releases/releases/tag/latest) is kept up to date. Its filenames stay the same, so the links above keep working.

Older builds stay available on the [releases page](https://github.com/onyva-platform/releases/releases). Their filenames include the version, for example `ONYVA-202610.22.1-macos.dmg`.

Release notes are grouped into **New**, **Improved**, and **Fixed**.

## Install

- **Windows:** open `ONYVA-windows-setup.exe` and follow the installer.
- **macOS:** open `ONYVA-macos.dmg` and move ONYVA to Applications.
- **Linux:** make the AppImage executable, then run it:

  ```bash
  chmod +x ONYVA-linux.AppImage
  ./ONYVA-linux.AppImage
  ```

GitHub also lists "Source code (zip)" and "Source code (tar.gz)" on each release. Those archives contain only this download page, not the ONYVA application.
